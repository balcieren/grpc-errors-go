# grpc-errors-go

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Go Reference](https://pkg.go.dev/badge/github.com/balcieren/grpc-errors-go.svg)](https://pkg.go.dev/github.com/balcieren/grpc-errors-go)

**Define errors in `.proto`, generate type-safe Go constructors, catch bugs at compile time.**

A proto-first error handling package for **standard gRPC** (`google.golang.org/grpc`). Define your errors alongside your service definitions, run `buf generate`, and get fully typed constructor functions with struct parameters — no magic strings, no typos, no runtime surprises.

```protobuf
// Define in your .proto file
option (errors.v1.rpc_error) = {
  error_code: "ERROR_USER_NOT_FOUND"
  message: "User '{{id}}' not found"
  status_code: NOT_FOUND
};
```

```go
// Use the generated typed constructor
return nil, userv1.NewErrUserNotFound(userv1.UserNotFoundParams{
    Id: req.Msg.Id,  // ← IDE autocomplete, compile-time checked
})
```

> Wrong field name? **Won't compile.** Missing field? **IDE warns you.** Wrong error code? **Doesn't exist.**

## Features

| Feature                       | Description                                                    |
| ----------------------------- | -------------------------------------------------------------- |
| 🔧 **Proto-first**            | Errors live in `.proto` files next to your service definitions |
| ⚡ **Generated Constructors** | `NewErrXxx(XxxParams{})` — fully typed, zero string literals   |
| 🎯 **Compile-time safe**      | `ErrorCode` type + struct params catch all typos at build      |
| 📝 **Template Messages**      | `{{placeholder}}` → struct fields, validated at runtime        |
| 🔄 **Retryable Errors**       | Mark errors as retryable with custom retry delays in proto     |
| 🪝 **Interceptors**           | Unary + streaming hooks for logging, metrics, and tracing      |
| ✅ **errors.Is / errors.As**  | Idiomatic Go error matching via `ErrorCode` & `CodedError`     |
| 🔀 **Error Matching**         | `MatchesError` + `MatchError` (switch-like, deterministic)     |
| 🔨 **Error Builder**          | Chainable API: `.WithFieldViolation().WithRetryDelay().Build()` |
| 🌐 **RFC 7807**               | `ToProblemDetails()` for REST/HTTP adapters                    |
| 🏷️ **Configurable Domain**    | `SetDomain("myapp")` for `google.rpc.ErrorInfo`                |
| 🧩 **Context-aware**          | `NewCtx()` + `SetContextExtractor()` for trace IDs, etc.       |
| 📊 **Customizable Logging**   | `SetErrorLogger()` + `SetValidationLogger()` for any log pkg   |
| 🚡 **gRPC Trailers**          | `x-error-code` / `x-retryable` trailers for fast client access |

## Step 2: Define Errors in Proto

Errors are defined at the **method level** using the `errors.v1.rpc_error` option:

```protobuf
syntax = "proto3";
package user.v1;

import "errors/v1/error.proto";

service UserService {
  rpc GetUser(GetUserRequest) returns (User) {
    option (errors.v1.rpc_error) = {
      error_code: "ERROR_USER_NOT_FOUND"
      message: "User '{{id}}' not found"
      status_code: NOT_FOUND
    };
  };

  rpc CreateUser(CreateUserRequest) returns (User) {
    option (errors.v1.rpc_error) = {
      error_code: "ERROR_EMAIL_EXISTS"
      message: "Email '{{email}}' is already registered"
      status_code: ALREADY_EXISTS
    };
  };
}
```

## Step 3: Generate Code

```bash
buf generate
```

This creates a `*_grpc_errors.go` file with typed constructors, matchers, and extractors.

```go
// Code generated by protoc-gen-grpc-errors-go. DO NOT EDIT.
package userv1

import (
    gerr "github.com/balcieren/grpc-errors-go"
    "google.golang.org/grpc/codes"
)

// Error code constants
const (
    ErrUserNotFound gerr.ErrorCode = "ERROR_USER_NOT_FOUND"
    ErrEmailExists  gerr.ErrorCode = "ERROR_EMAIL_EXISTS"
)

func init() {
    gerr.RegisterAll([]gerr.Error{
        { ErrorCode: ErrUserNotFound, MessageTpl: "User '{{id}}' not found", StatusCode: codes.NotFound },
        { ErrorCode: ErrEmailExists,  MessageTpl: "Email '{{email}}' registered", StatusCode: codes.AlreadyExists },
    })
}

// Typed constructor with struct params
type UserNotFoundParams struct {
    Id string
}

func NewErrUserNotFound(p UserNotFoundParams) error {
    return gerr.New(ErrUserNotFound, gerr.M{"id": p.Id})
}

// Client-side matcher
func IsUserNotFound(err error) bool {
    return gerr.MatchesError(err, ErrUserNotFound)
}

// Typed ErrorInfo extractor
func ExtractUserNotFoundInfo(err error) *errdetails.ErrorInfo {
    if !IsUserNotFound(err) { return nil }
    info, _ := gerr.ExtractErrorInfo(err)
    return info
}
```

## Step 4: Use in Your Handlers

```go
func (s *UserServer) GetUser(ctx context.Context, req *pb.GetUserRequest) (*pb.User, error) {
    user, err := s.db.FindUser(ctx, req.Id)
    if err != nil {
        return nil, userv1.NewErrUserNotFound(userv1.UserNotFoundParams{
            Id: req.Id,
        })
    }
    return user, nil
}
```

## Step 5: Handle Errors on the Client

```go
_, err := client.GetUser(ctx, &pb.GetUserRequest{Id: "123"})
if err != nil {
    switch {
    case userv1.IsUserNotFound(err):
        fmt.Println("User does not exist")
    case userv1.IsEmailExists(err):
        fmt.Println("Email already registered")
    default:
        fmt.Println("Unexpected error:", err)
    }
}
```

## gRPC Trailer Metadata

By default, the library attaches `x-error-code` and `x-retryable` headers as gRPC trailing metadata (in addition to the `google.rpc.ErrorInfo`/`RetryInfo` protobuf details). This allows load balancers or lightweight clients to inspect error codes without parsing protobuf details.

```go
// On the server: explicitly send trailers before returning the error
if err != nil {
    gerr.SendTrailer(ctx, err)
    return err
}
```

On the client, trailers are available via `grpc.TrailerMetadataKey`:

```go
var trailer metadata.MD
_, err := client.GetUser(ctx, req, grpc.Trailer(&trailer))
if err != nil {
    if vals := trailer.Get(gerr.TrailerKeyCode); len(vals) > 0 {
        fmt.Println("error code from trailer:", vals[0])
    }
    if vals := trailer.Get(gerr.TrailerKeyRetryable); len(vals) > 0 {
        fmt.Println("retryable:", vals[0])
    }
}
```

### Protobuf Details (primary)

The primary source of error metadata is `google.rpc.ErrorInfo` and `google.rpc.RetryInfo`, attached as protobuf details on the gRPC status:

```go
if info, ok := gerr.ExtractErrorInfo(err); ok {
    fmt.Println(info.Reason)   // "ERROR_USER_NOT_FOUND"
    fmt.Println(info.Metadata) // map[id:123]
}

if retry, ok := gerr.ExtractRetryInfo(err); ok {
    fmt.Println("retryable!")
}

if code, ok := gerr.ExtractErrorCode(err); ok {
    fmt.Println("error code:", code)
}
```

## API Reference

### Error Creation

| Function                          | Description                                   |
| --------------------------------- | --------------------------------------------- |
| `New(code, data)`                 | Create error from registry with template data |
| `NewWithMessage(code, msg, data)` | Override default template message             |
| `Newf(code, format, args...)`     | fmt.Sprintf-style formatting                  |
| `Wrap(code, err, data)`           | Wrap underlying error with context            |
| `FromCode(code, msg)`             | Create directly from codes.Code               |
| `NewWithRetry(code, data, delay)` | Create error with custom retry delay          |
| `NewCtx(ctx, code, data)`         | Create error with context-extracted metadata  |
| `NewBuilder(code, data)`          | Chainable builder for complex errors          |
| `WithFieldViolation(err, field, msg)` | Add `google.rpc.BadRequest` FieldViolation    |

### Error Inspection

| Function                       | Description                                |
| ------------------------------ | ------------------------------------------ |
| `FromError(err)`               | Extract `Error` definition from metadata   |
| `ExtractErrorCode(err)`        | Get just the error code string             |
| `ExtractErrorInfo(err)`        | Extract `google.rpc.ErrorInfo` detail      |
| `ExtractRetryInfo(err)`        | Extract `google.rpc.RetryInfo` detail      |
| `IsRetryable(codeOrErr)`       | Check if an error code/error is retryable  |
| `StatusCode(code)`             | Get the `codes.Code` for an error code     |
| `MatchesError(err, code)`      | Check if an error matches a code           |
| `MatchError(err, matchers)`    | Switch-like error matching                 |
| `ToProblemDetails(err)`        | Convert to RFC 7807 Problem Details        |
| `HTTPStatusFromCode(code)`     | Map codes.Code → HTTP status code          |
| `SendTrailer(ctx, err)`        | Attach x-error-code/x-retryable trailers   |

### Registry

| Function           | Description                                |
| ------------------ | ------------------------------------------ |
| `Register(err)`    | Register an error definition               |
| `RegisterAll(errs)`| Register multiple error definitions        |
| `Lookup(code)`     | Look up an error definition by code        |
| `MustLookup(code)` | Look up or panic if not found              |
| `Codes()`          | Return sorted list of all registered codes |

### Interceptors

```go
// Unary
interceptor := gerr.ErrorInterceptor(func(ctx context.Context, err error, def gerr.Error) {
    slog.ErrorContext(ctx, "rpc error",
        "code", def.ErrorCode,
        "status_code", def.StatusCode,
        "retryable", def.Retryable,
    )
})

s := grpc.NewServer(grpc.UnaryInterceptor(interceptor))

// Streaming
streamInterceptor := gerr.StreamingErrorInterceptor(func(ctx context.Context, err error, def gerr.Error) {
    slog.ErrorContext(ctx, "streaming rpc error", "code", def.ErrorCode)
})

s := grpc.NewServer(grpc.StreamInterceptor(streamInterceptor))
```

### Error Builder

```go
err := gerr.NewBuilder(gerr.ErrInvalidArgument, nil).
    WithFieldViolation("email", "already registered").
    WithRetryDelay(5 * time.Second).
    WithDomain("myapp").
    WithMessage("custom message").
    WithDetail(detail).
    Build()
```

### Logging

```go
// Zap
logger, _ := zap.NewProduction()
gerr.SetErrorLogger(func(code string, statusCode codes.Code, retryable bool, data gerr.M) {
    logger.Info("error created",
        zap.String("code", code),
        zap.String("status_code", statusCode.String()),
        zap.Bool("retryable", retryable),
    )
})

// Sentry
gerr.SetErrorLogger(func(code string, statusCode codes.Code, retryable bool, data gerr.M) {
    sentry.WithScope(func(scope *sentry.Scope) {
        scope.SetTag("error_code", code)
        scope.SetContext("data", data)
        sentry.CaptureMessage("Error created: " + code)
    })
})

// Log validation failures
gerr.SetValidationLogger(func(code string, data gerr.M, err error) {
    slog.Error("template validation failed", "code", code, "error", err)
})
```

### errors.Is Support

ErrorCode implements the error interface, enabling idiomatic Go error matching:

```go
err := gerr.New(gerr.ErrNotFound, nil)
if errors.Is(err, gerr.ErrNotFound) {
    fmt.Println("not found")
}
```

## Concurrency Safety

All global state (registry, domain, loggers, context extractor) is protected for concurrent use:

- **Registry**: Copy-on-write with `atomic.Value` for lock-free reads, `sync.Mutex` for writes
- **Loggers**: `atomic.Value` for `SetErrorLogger()` / `SetValidationLogger()`
- **Domain**: `atomic.Value`
- **Context Extractor**: `atomic.Value`
- **Error Builder**: `WithDomain()` overrides domain per-error without mutating global state

All error creation functions (`New`, `Wrap`, `NewWithMessage`, etc.) are safe to call concurrently from multiple goroutines.

## Alternative: Manual Usage (Without Proto)

If you don't use proto-based definitions, you can define errors manually:

```go
import gerr "github.com/balcieren/grpc-errors-go"

const ErrEmailTaken gerr.ErrorCode = "ERROR_EMAIL_TAKEN"

func init() {
    gerr.Register(gerr.Error{
        ErrorCode:   ErrEmailTaken,
        MessageTpl:  "Email '{{email}}' is taken",
        StatusCode:  codes.AlreadyExists,
    })
}

// Use with the generic API
return nil, gerr.New(ErrEmailTaken, gerr.M{"email": email})

// Or use built-in codes
return nil, gerr.New(gerr.ErrNotFound, nil)
return nil, gerr.Wrap(gerr.ErrInternal, dbErr, nil)
return nil, gerr.Newf(gerr.ErrNotFound, "User %q not found", id)
```
